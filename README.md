# Sistema de Restaurante — Projeto 1

Sistema em Java (console) com cardápio, pedidos, personalização e fechamento do dia.

## O que foi feito
- Nível 1: Lanche, Pedido, GerenciadorPedidos, MenuConsole, RestauranteFacade, Main
- Nível 2: interface ItemCardapio, LancheFactory, adicionais com Decorator, testes JUnit
- Nível 3: retirar ingredientes, modificar pedido, combinações com HashSet, tratamento de entrada inválida

## Padrões usados
Facade, Factory e Decorator.
